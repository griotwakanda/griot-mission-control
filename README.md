# Wakanda Mission Control (Vue + Static Snapshots)

Mobile-first operational dashboard for Griot, built with **Vue 3 + Vite** and powered by static JSON snapshots.

## What changed

- Firebase removed from runtime and dependencies
- Dashboard now reads snapshot files from `public/data/*.json`
- Modular tabs for:
  - Overview
  - Agents
  - Automations
  - Repos
  - Board
  - Log
- Deployable as a static site (Netlify-friendly)

## Snapshot files

The frontend reads:

- `/data/overview.json`
- `/data/agents.json`
- `/data/automations.json`
- `/data/repos.json`
- `/data/board.json`
- `/data/worklog.json`

These are initial seeds and can later be regenerated by scripts.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Static deployment (Netlify)

This project is fully static. Recommended deploy settings:

- **Build command:** `npm run build`
- **Publish directory:** `dist`

CLI deploy example:

```bash
npm run build
npx netlify deploy --dir=dist --prod
```

## Security note

If this dashboard includes sensitive operational details, protect access before public exposure (Netlify auth, site passwording, private network, etc.).
